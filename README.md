# Onflo Mobile dashboard

One page: the Onflo admin app prototype running in a phone frame, next to what is in the app today,
what is in progress, and the latest updates.

- `index.html`, `catalog.js` are the page. Plain HTML, no build step: edit `catalog.js` to change content.
- `app/` is a web build of the mobile prototype (Flutter). Rebuilt by hand from the source branch; see `app/BUILD.md`.
- `clips/` holds short recordings that play inside a feature row.

Served by GitHub Pages from `main`.
